# Features

End-user features available in the HL Helper web UI. Some features require specific roles or scopes—your administrator controls what you can access.

## Available

### [Login & MFA](./login.md)

Sign in, set up multi-factor authentication (TOTP, passkey, WebAuthn), recover lost access, and manage your session.

## Planned

The following features are in active development. See the [Roadmap](../../_planned/) for timelines and status.

- **Fleet view & host detail** — Dashboard, host list, status monitoring, uptime tracking
- **Findings & advisories** — Security issue aggregation, CVE details, advisory filtering
- **Update triggers** — Check for available updates, approve and deploy patches
- **Container ops** — Discover and manage Docker/Podman containers
- **Terminal access** — Browser-based terminal, file transfer over gRPC
- **Power controls** — Reboot, shutdown, wake-on-LAN
- **Plugins** — Custom workflows and extensions
- **Notifications** — Alerts via email, Slack, Discord, webhook, etc.
