## Core Concepts

- **Hosts** -- managed Linux/Unix machines running the HL Helper agent
- **Commands** -- signed operations dispatched from the control plane
- **Plugins** -- sandboxed extensions for custom workflows
- **Posture** -- security findings aggregated across the fleet
